  • Always start with "Design a [screen] for HealthSync, a medical booking platform"
  • Always specify viewport size (desktop 1440px, mobile 375px)
  • Always mention color: teal #006D77 primary, coral #E29578 secondary
  • Always specify font: Plus Jakarta Sans
  • Name real DB fields in prompts (e.g. "clinician_type, day_of_week, recurrence_type")
  • Request both desktop + mobile variants in one prompt
  • Mention specific MUI components by name for Stitch to mirror the style
  • Include empty states, loading states, error states in the prompt
  • Request hover states and active states explicitly
  • For complex screens: do one Stitch prompt per section of the page
